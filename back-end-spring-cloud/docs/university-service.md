# university-service

## 定位

大学阶段学业服务，覆盖专业、课程树、课程分类、学生课程成绩、毕业进度、GPA 模拟和论文建议。

## 数据库

- `cot_university`

## 主要对象

- `Major`
- `Course`
- `CourseCategory`
- `GraduationRequirement`
- `StudentCourse`
- `Paper`
- `Suggestion`

## 路由

- `/api/university/**`
- `/api/university/major/**`
- `/api/course/**`
- `/api/course-category/**`
- `/api/student-course/**`
- `/api/paper/**`
